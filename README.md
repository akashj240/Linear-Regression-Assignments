# Linear Regression Assignments

This repository contains two Machine Learning projects developed using **Simple Linear Regression** with Python and Excel.

## Projects

### 1. Delivery Time Prediction

**Objective:** Predict delivery time based on sorting time.

- Dataset: `delivery_time.csv`
- Independent Variable: Sorting Time
- Dependent Variable: Delivery Time
- Algorithm: Simple Linear Regression
- Tools: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn and Excel

### 2. Salary Prediction

**Objective:** Predict salary based on years of experience.

- Dataset: `Salary_Data.csv`
- Independent Variable: YearsExperience
- Dependent Variable: Salary
- Algorithm: Simple Linear Regression
- Tools: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn and Excel

*Note: The second dataset predicts salary from years of experience; it does not contain salary hike percentages.*
